# Scope — Growth package (salon demo)

This repo is the **Growth** portfolio demo: a Melbourne hair salon site with more structure and conversion paths than a one-page tradie brochure.

## Included in this demo

- Multi-section marketing page (hero, services + prices, gallery, team, location/hours, booking request)
- Sticky header with primary CTA
- Mobile-first layout (Astro + Tailwind)
- Sample “Growth package” footer for outreach honesty
- Static hosting (no database, no live booking)

## Growth vs other packages

| | Starter (tradie) | **Growth (this site)** | Pro (music studio) |
|---|---|---|---|
| Layout | Single brochure page | Multi-section / richer content | Multi-section + interactive tool |
| Pricing shown | Trust bullets | Service menu with AUD prices | Lesson packages |
| Visuals | Hero + copy | Gallery + team | Teachers + scheduler UI |
| Conversion | Call Now + quote form | Booking **request** form | Slot picker (demo calendar) |
| Backend | None | None (form UI only) | None in demo; real booking needs Cal.com or custom API |

## Typical client deliverable (Growth)

- Custom branding, copy, and photos
- Service list with real prices
- Working enquiry/booking-request form (e.g. Formspree, Resend, or CRM)
- Google Maps link / embed
- Deploy to Vercel (or similar) + domain connect

## Not included unless quoted

- Live calendar / instant booking
- Payments / deposits
- Client login / membership
- Ongoing SEO retainers or content photography
