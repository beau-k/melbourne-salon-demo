# Lumen Hair Studio — Growth demo

Public portfolio demo for a **Melbourne salon** website (Growth pricing tier).

**Live demo:** _(add Vercel URL after deploy)_

## Stack

- Astro 7
- Tailwind CSS 4
- Static output (no server required)

## Local

```bash
npm install
npm run dev
```

Open the URL printed in the terminal (usually `http://localhost:4321/`).

```bash
npm run build
npm run preview
```

## Docs

- [docs/SCOPE.md](docs/SCOPE.md) — what’s in Growth vs Starter/Pro

## Deploy (Vercel)

1. Push this repo to GitHub
2. Import the project in Vercel (framework: Astro)
3. Prefer project name `melbourne-salon-demo` for a cleaner `*.vercel.app` URL
